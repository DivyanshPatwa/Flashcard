# 🤖 AI Flashcard Generator

An AI-powered web application that converts study material into interactive flashcards.

## 🚀 Features

- Generate AI-powered flashcards from study material
- Choose the number of flashcards: 5, 10, or 15
- View questions and reveal answers
- Navigate between flashcards using Previous/Next buttons
- Clear the generated flashcards and start again
- Simple and user-friendly interface

## 🛠️ Technologies Used

- Python
- Flask
- Hugging Face Inference API
- HTML
- CSS
- JavaScript
- python-dotenv
